# ParamIQ Platform Knowledge Base / Base de Connaissance ParamIQ

## [EN] Overview
ParamIQ is an intelligent platform for auditing, validating, and comparing XBRL-CSV reporting files. It is designed for SBS (Service-Based Software) teams and powered by Artificial Intelligence.

## [FR] Présentation
ParamIQ est une plateforme intelligente pour l'audit, la validation et la comparaison de fichiers de rapport XBRL-CSV. Elle est conçue pour les équipes SBS (Service-Based Software) et propulsée par l'Intelligence Artificielle.

## [EN] Module M1: Validation XBRL-CSV
Automatic control of structure, mandatory columns, contextRef formats, and duplicates. Generates userTemplates.

## [FR] Module M1: Validation XBRL-CSV
Contrôle automatique de la structure, des colonnes obligatoires, des formats contextRef et des doublons. Génère des templates utilisateurs (userTemplates).

## [EN] Module M2: Cell-by-Cell Comparison
Precise diff between two versions of the same report. Detects additions, deletions, and modifications with delta calculations.

## [FR] Module M2: Comparaison Cellule par Cellule
Différentiel précis entre deux versions du même rapport. Détecte les ajouts, suppressions et modifications avec calculs de delta.

## [EN] Module M3: Form Generator
Automatic generation of XBRL forms with generic datatypes (monetary, numeric, boolean, dates).

## [FR] Module M3: Générateur de Formulaires
Génération automatique de formulaires XBRL avec types de données génériques (monétaires, numériques, booléens, dates).

## [EN] Module M4: ESPF to CSV Conversion
Converts ESPF format to standard XBRL-CSV with AI assistance for ambiguous mappings.

## [FR] Module M4: Conversion ESPF vers CSV
Convertit le format ESPF en XBRL-CSV standard avec l'assistance de l'IA pour les correspondances ambiguës.

## [EN] Module M5: Automated Pipeline
Initialisation Git with pattern dictionaries, duplication pipelines, and e2e scenarios.

## [FR] Module M5: Pipeline Automatisé
Initialisation Git avec dictionnaires de modèles, pipelines de duplication et scénarios de bout en bout (e2e).

## [EN] Module M6: Automation Scripting
Automated launching via PowerShell for recurring reporting tasks.

## [FR] Module M6: Scripting d'Automatisation
Lancement automatisé via PowerShell pour les tâches de reporting récurrentes.

## [EN] Module M7: AI Assistant
Specialized chatbot for XBRL expertise, offering explanations in French/English and suggesting corrections.

## [FR] Module M7: Assistant IA
Chatbot spécialisé pour l'expertise XBRL, offrant des explications en Français/Anglais et suggérant des corrections.

## [EN] Module M8: Automatic PDF Reports
Generates professional quality reports summarizing validations, statistics, and errors by severity.

## [FR] Module M8: Rapports PDF Automatiques
Génère des rapports de qualité professionnelle résumant les validations, les statistiques et les erreurs par niveau de gravité.

## [EN] User Roles
- Admin SBS: Full platform access. Manages users, views all histories, configures pipeline parameters, and exports global PDF reports.
- Analyst SBS (Consultant): Access to daily processing modules (Upload, Validation, Comparison, AI Assistant).

## [FR] Rôles Utilisateurs
- Administrateur SBS : Accès complet à la plateforme. Gère les utilisateurs, consulte les historiques, configure les paramètres du pipeline et exporte les rapports PDF globaux.
- Analyste SBS (Consultant) : Accès aux modules de traitement quotidien (Chargement, Validation, Comparaison, Assistant IA).

## [EN] Workflow Steps
1. Upload: Drop CSV, XLSX, or XML files (up to 50MB).
2. Validation: Auto-analysis of structure and datatypes in seconds.
3. AI Analysis: Detects anomalies, compares versions, and explains errors.
4. Report & Delivery: Export comparisons, launch pipeline, and archive.

## [FR] Étapes du Workflow
1. Chargement : Déposez des fichiers CSV, XLSX ou XML (jusqu'à 50 Mo).
2. Validation : Auto-analyse de la structure et des types de données en quelques secondes.
3. Analyse IA : Détecte les anomalies, compare les versions et explique les erreurs.
4. Rapport & Livraison : Exportez les comparaisons, lancez le pipeline et archivez.
